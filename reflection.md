# Reflection

It took a while to finish this project due to getting the arm to talk to the WSL/Linux and ended up using a VM instead of WSL. Changing over to the VM had its perks of being easy to set up and work on when I need to but has a downside of not having as many resources to help set up the packages properly and the commands not working or just me missing sections. 

Creating the code to talk to my xArm was easy to implement having the previous assessment covering that area on how to apply the movemetns efficently. The Pygame took some research to get working on how to get images to work and how to find the value with the colour picker to count the score. In the end it was a fun project I enjoyed making being able to interact with a real robot getting it talk through publishing and subscribing messages. 

If I were to do something differently I would change it from a colour picker to find the distance from the centre to count the score as even if you hit in the yellow circle you clicked on top of the black text of '10'. Another addition is depending where you clicked it will create then after move around depending where you clicked of a arrow hole showing the last position you clicked and makes it more interactive.
